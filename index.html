FAQ

Questions, answered

Everything players ask before installing the Ball VS Ball Script.

Is the Ball VS Ball Script free to use? +

Yes. The project is fully free and open source. Every feature — auto-aim targeting, ESP ball tracker, speed and size tweaks, and the instant win trigger — is included with no premium tier or paywall. You can review the source on GitHub before running anything.

Which Windows versions are supported? +

The loader is built and tested for Windows 10 and Windows 11 (64-bit). It runs standalone with no external runtimes, and the auto-updater keeps it compatible with the latest Roblox client patches.

Will the ESP tracker and auto-aim update automatically? +

Yes. The script checks for updates on launch and pulls the newest offsets and targeting logic whenever Roblox ships a patch. If something breaks mid-update, use the one-click rollback to restore the previous working build.

Can I disable individual features like the instant win trigger? +

Absolutely. Every module is toggleable from the overlay panel. Many players run only the ESP ball tracker, while others keep auto-aim and speed tweaks on for competitive lobbies. Your choices persist between sessions.
